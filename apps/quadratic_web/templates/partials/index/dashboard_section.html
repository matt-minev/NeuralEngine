Quick Start Guide

Getting Started

  1. Upload your quadratic equation dataset (CSV format)
  2. Select training scenarios and configure parameters
  3. Train neural network models
  4. Make predictions and analyze results

Data Format

Expected CSV columns:

a, b, c, x1, x2

Where ax² + bx + c = 0 has solutions x1 and x2
